# decoder

The goal of decoder is to decode coded and perhaps cryptical variables
to more understandable descriptive labels.

## Installation

You can install the released version of decoder from
[CRAN](https://CRAN.R-project.org) with:

``` r

install.packages("decoder")
```

And the development version from
[GitHub](https://github.com/eribul/decoder/) with:

``` r

# install.packages("pak")
pak::pkg_install("eribul/decoder")
```
