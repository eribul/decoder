# hemort and hemort2 codes (geographical codes)

Both `hemort` and `hemort2` combines regional codes for lan, kommun and
forsamling. `hemort` is the official (but rather old) code used within
RCC. `hemort2` is an updated version combining
[`lan`](https://eribul.github.io/decoder/reference/lan.md),
[`kommun`](https://eribul.github.io/decoder/reference/kommun.md) and
[`forsamling`](https://eribul.github.io/decoder/reference/forsamling.md)
