# Extra functions to apply to decoded variables using decode

See section "extra_functions" at the
[decode](https://eribul.github.io/decoder/reference/decode.md) help
page!

## Usage

``` r
kungalv2Storgoteborg(x)

kungalv2Fyrbodal(x)

real_names(x)

short_region_names(x)
```

## Arguments

- x:

  The decoded variable to be further processed. This argument should not
  be set by the user. It is used only internally by the function from
  which it is called.
